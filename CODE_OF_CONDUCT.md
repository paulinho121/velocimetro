# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo, esperamos que todas as pessoas que participam do projeto — em
issues, pull requests, revisões e qualquer outro espaço — :

- tratem os outros com respeito e empatia, independentemente de experiência,
  identidade ou origem;
- deem e recebam críticas construtivas com foco no código, não na pessoa;
- evitem linguagem ou conteúdo ofensivo, assédio, ataques pessoais e exposição
  de dados privados de terceiros.

## Como reportar

Se você presenciar ou sofrer um comportamento inaceitável, avise os mantenedores
em particular pelo [formulário de relato privado do GitHub](https://github.com/paulinho121/velocimetro/security/advisories/new)
ou mandando mensagem direta para [@paulinho121](https://github.com/paulinho121).
Todos os relatos serão tratados com sigilo.

Os mantenedores podem remover comentários, commits ou contribuições que violem
este código, e bloquear temporária ou permanentemente quem o desrespeitar.
