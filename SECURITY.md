# Segurança

Encontrou uma vulnerabilidade? **Não abra uma issue pública.**

Use o [relato privado de vulnerabilidade](https://github.com/paulinho121/velocimetro/security/advisories/new)
do GitHub. Descreva o problema, como reproduzir e o impacto esperado. Você terá
uma resposta assim que possível.

Só a versão mais recente (branch `main`, publicada na Vercel) recebe correções.
